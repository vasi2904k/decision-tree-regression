# 🧠 Decision Tree Regression Project

## 📌 Overview
This project uses Decision Tree Regressor to predict insurance charges.

## 📊 Dataset
- insurance dataset
- Features: age, bmi, children, smoker, region

## ⚙️ Model
- Decision Tree Regressor
- Hyperparameter tuning using GridSearchCV

## 📈 Results
- Base Model R²: 0.89
- Tuned Model R²: 0.89

## 🔍 Conclusion
Tuned model reduces overfitting and generalizes better.

## 🛠️ Tech Stack
